ЧТО ЭТО ЗА ПРОЕКТ
-----------------
Обучающий сайт-справочник по информационной безопасности. В нём собраны
50 вопросов по дисциплине, к каждому вопросу приведены полный ответ с
пояснениями, тема из учебного плана и ссылки на источники
(федеральные законы, ГОСТ, приказы и методики ФСТЭК России).

Формулировки вопросов, ответы и источники перенесены из предоставленного
Word-документа. Для источников без прямого URL добавлена ссылка на поиск по названию.


КАК ЗАПУСТИТЬ САЙТ
------------------
Способ 1 (самый простой):
  1. Откройте папку проекта.
  2. Дважды щёлкните по файлу index.html.
  3. Сайт откроется в браузере по умолчанию.

Способ 2 (через локальный сервер — если нужно проверить поиск с
URL-адресом):
  Откройте терминал в папке проекта и выполните:

      python3 -m http.server 8000

  затем откройте в браузере:  http://localhost:8000

Примечание: сайт работает и без сервера, сборка не требуется.


ФАЙЛЫ ПРОЕКТА
--------------
index.html
    Разметка страницы: верхняя панель с логотипом-щитом, главный экран,
    каталог вопросов, блок поиска и фильтров, раздел «Полезные источники»
    и подвал с кнопкой «Наверх».

style.css
    Оформление сайта: цветовая палитра (кремовый фон, тёмно-зелёный
    основной цвет, салатовый акцент, белые карточки), типографика,
    анимация раскрытия ответов, адаптивная вёрстка для компьютеров,
    планшетов и смартфонов.

data.js
    Все 50 вопросов в виде массива объектов. Каждый объект содержит:
        number    — номер вопроса (1…50);
        topic     — тема из учебного плана;
        question  — полная формулировка вопроса;
        answer    — полный текст ответа (абзацы разделены пустой строкой);
        sources   — массив источников { title, url }.
    Чтобы отредактировать текст вопроса или ответа, достаточно изменить
    этот файл — страница подстроится автоматически, отдельные HTML-страницы
    создавать не нужно.

script.js
    Логика сайта:
      • построение карточек вопросов из массива window.QUESTIONS;
      • раскрытие и сворачивание ответов с плавной анимацией
        (несколько ответов можно держать открытыми одновременно);
      • поиск по номеру вопроса, тексту вопроса, теме, ответу
        и названиям источников;
      • фильтры по диапазонам номеров: 1–10, 11–20, 21–30, 31–40, 41–50;
      • кнопка сброса поиска и фильтров и сообщение «Ничего не найдено»;
      • раздел «Полезные источники» с уникальными документами;
      • плавная прокрутка к каталогу и кнопка «Наверх»;
      • горячая клавиша «/» — переход к строке поиска.


КАК ЭТО РАБОТАЕТ
----------------
1. При открытии страницы data.js отдаёт массив из 50 вопросов.
2. script.js создаёт для каждого вопроса карточку: номер, тему,
   формулировку и кнопку «Открыть ответ».
3. При нажатии на кнопку карточка плавно раскрывается и показывает
   тему, полный вопрос, полный ответ, раздел «Источники» с названиями
   документов и рабочими ссылками.
4. Поиск и фильтры скрывают неподходящие карточки; счётчик показывает,
   сколько вопросов найдено из 50.


ТРЕБОВОВАНИЯ И ЗАВИСИМОСТИ
--------------------------
Браузер с поддержкой JavaScript (любой современный: Chrome, Firefox,
Safari, Edge).

Сторонние библиотеки, платные сервисы, аккаунты и сборка НЕ требуются.
Внешние зависимости отсутствуют, поэтому сайт работает офлайн.
Внешние ссылки (нормативные документы) открываются в новой вкладке
и требуют подключения к интернету.
